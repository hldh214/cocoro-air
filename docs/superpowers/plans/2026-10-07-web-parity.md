# Sharp 网页功能接入实施计划

目标：以用户授权登录后的 KI-PX70 网页为验收依据，覆盖其设备控制、状态、维护、宠物、通知、电费与历史功能。

架构：保留账号登录与已有温湿度实体 unique_id。同步 API 经 executor 与锁串行执行；每设备一个共享 coordinator；实体承载日常状态与控制，复杂记录/配置由有输入验证的 HA 服务承载，读服务返回响应数据。临时调研 cookie 不进入产品。

1. 在授权浏览器逐页查看实际菜单；只读抓取真实 spec、状态、耗材、宠物、通知、电费响应。建立网页/HA 覆盖表，标记不支持项。
2. protocol.py：测试停止、上下限、测量标志、能力过滤和准确命令载荷；实现状态解析、模式列表与控制构造。
3. cloud.py：测试通知合并、宠物合法参数、耗材计算/维护载荷、分时电费编解码；实现纯协议函数。
4. api.py：保留登录逻辑，统一 HTTP/业务错误与仅一次认证重试；增加详细状态、云配置读写与读回、close；mock HTTP 验证错误与请求格式。
5. coordinator.py / entity.py：每设备共享刷新；辅助云配置低频更新；命令串行后重新读回；离线、认证错误进入 HA 标准错误流程。
6. fan / switch / number / binary_sensor / sensor / button：按真实能力创建；复杂记录与维护/宠物/电费通过服务开放；保持旧实体身份。
7. services.py / services.yaml：公开历史、费用、宠物 CRUD、通知、分时电价、维护完成等操作；严格校验输入与所选设备范围。维护重置不作为实机回归动作。
8. 集成测试、编译和静态检查；HA 2026.8.1 环境验证实体注册与卸载、服务响应。真实会话只读核对；有限控制动作后恢复原状态。README 写明覆盖、用法及尚未验证项目。

测试使用 unittest + httpx.MockTransport，HA 生命周期用兼容版本的真实 HA 环境验证。原始真实响应只存在 /tmp，仓库仅保存人工构造的无隐私测试样本。
